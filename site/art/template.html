Download

On macOS, Windows and Linux.

macOSyour system

Apple silicon Macs

  1. Open the .dmg and drag Ambient to Applications.
  2. The first time, right-click Ambient → Open, then Open again.
  3. Approve Ambient’s network extension when macOS asks.
Download .dmg Apple silicon
Windowsyour system

Windows, x64

  1. If SmartScreen says “Windows protected your PC”, choose More info → Run anyway.
  2. Windows asks for an administrator to install, and again when capture starts.
Download .exe installer · x64.msi for IT deployment
Linuxyour system

Ubuntu, Debian

  1. Install with sudo apt install ./Ambient_0.1.0_amd64.deb.
  2. Setup asks for an administrator password once.
Download .deb x64

These are unsigned early builds, so each system warns you before the first run. To read your apps, Ambient adds its own certificate and captures network traffic on your device; your system asks you to confirm both. Every build comes from the public code: read the source on GitHub.
